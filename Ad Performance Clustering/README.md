# Ad Performance Clustering

## Project Overview

This project analyzes digital advertising performance using CPM, CPC, and CTR metrics.

The objective is to identify meaningful advertising performance segments using statistical analysis, outlier treatment, hierarchical clustering, and K-Means clustering.

## Business Problem

Digital advertising campaigns can differ significantly in cost and engagement.

The analysis aims to identify groups of campaigns with similar performance characteristics and translate these groups into actionable business segments.

## Key Metrics

- CPM — Cost Per Mille
- CPC — Cost Per Click
- CTR — Click Through Rate

## Methodology

1. Data exploration
2. Distribution analysis
3. Outlier identification
4. Winsorisation
5. Feature standardisation
6. Hierarchical clustering
7. K-Means clustering
8. Elbow analysis
9. Silhouette analysis
10. Cluster profiling
11. Business interpretation
