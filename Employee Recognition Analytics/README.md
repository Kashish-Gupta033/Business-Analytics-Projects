# Employee Recognition Analytics

## Project Overview

This Tableau project analyzes employee recognition and rewards activity to understand recognition patterns, reward spending, employee satisfaction, collaboration, and organizational trends.

The dataset contains employee recognition transactions recorded between January 2023 and December 2025 across multiple business units and locations in India.

## Business Problem

Organizations use employee recognition programs to encourage collaboration, innovation, customer focus, leadership, and teamwork.

This analysis explores how recognition activity and reward spending vary across departments, states, employee levels, recognition types, and time.

## Key Questions

- How much is being spent on employee recognition?
- Which departments account for the highest reward spending?
- How does recognition activity vary across states?
- What is the relationship between reward spending and employee satisfaction?
- Which recognition types receive the most points?
- How does recognition activity change over time?
- What patterns can be observed across employee levels?

## Dataset

Each row represents one employee recognition event.

Key fields include:

- Recognition Date
- Region
- State
- Business Unit
- Department
- Team
- Employee Level
- Recognition Type
- Reward Category
- Sender Gender
- Receiver Gender
- Points Awarded
- Monetary Value
- Recognition Count
- Collaboration Score
- Approval Time
- Employee Satisfaction

## Tableau Analysis

The Tableau workbook contains the following analytical views:

### Total Spend KPI

Provides an overall view of monetary value associated with employee recognition.

### Spend by Department

Compares recognition-related spending across departments.

### Spend by State

Provides a geographic view of recognition spending across India.

### Spend vs Satisfaction

Examines reward spending alongside employee satisfaction across employee levels.

### Points Heatmap

Shows reward points across recognition types and regions.

### Trend Over Time

Analyzes recognition-related metrics over time.

## Business Value

The analysis can help organizations understand recognition spending patterns and identify differences in recognition activity across departments, locations, employee levels, and recognition categories.

## Limitations

The analysis is based on the available recognition transaction data. Observed relationships between recognition activity, reward spending, collaboration, and satisfaction should not automatically be interpreted as causal relationships.

## Conclusion

This project demonstrates the use of Tableau to transform employee recognition transaction data into interactive business insights covering spending, geography, employee levels, recognition types, satisfaction, and trends over time.
